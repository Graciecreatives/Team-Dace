# Connected farm management implementation contract

Root owns server/utils/farm-workspace.js, server/api/management.js, persistence/schema registration, app/components/FarmWorkspace.vue, app/composables/useFarmWorkspace.js, offline utilities, dashboard integration and full validation.

Persistence: data.farmWorkspaces optional array (root adds validation). Workspace keyed id = owner user's id, userId same. Fields arrays plots,seasons,events,tasks,members,invitations,orders,movements,commands. Existing data.inventory, data.enterprises, data.records remain canonical owner-scoped physical stock/register/bookkeeping. No other top-level collections needed.

API GET /api/management?farmId=ownerId => {farms:[{id,name,role}],farm:{id,name,role},planning:{plots,seasons,events},operations:operationsView(data,ctx),business:businessView(data,ctx),inventory:[public stock],enterprises:[public register]}. POST {farmId,commandId(UUID),action,...fields} routes based on action. Each POST returns same snapshot plus optional result. Root owns atomic store(...,true), authentication/CSRF, commandId idempotency: exact payload replay returns current state without effects, mismatch409. Root creates ctx={user,farmId,role,workspace}; validates active member or owner, no silent fallback on forbidden farm. Root handles invitation acceptance before permission resolution. Default own farm.

Shared helpers from server/utils/farm-workspace.js: need(ctx,permission) throws403; text(value,label,max=200,optional=false) plain text; number(value,label,{min=0,max=1e9,integer=false}={}) strict finite number; date(value,label,optional=false) YYYY-MM-DD actual calendar date; findOwnedStock(data,ctx,id) finds data.inventory row userId=farmId else404; record(data,ctx,{title,category,amount,note,seasonId,sourceId}) creates canonical record id/createdAt/userId. root exports fail via h3 equivalent. need permissions: planning.write (owner/manager), event.create(owner/manager/worker), team.manage(owner), tasks.manage(owner/manager), tasks.complete(owner/manager/worker assigned only domain), stock.consume(owner/manager/worker assigned only domain), business.write/read(owner/manager). viewer read planning/tasks, no financials. Staff cannot edit legacy owner APIs because those remain self-scoped.

Production worker owns server/utils/farm-production.js exporting changeProduction(data,ctx,input), planningView(data,ctx). Actions plot.create (name,coordinates array [lat,lng] boundary >=3 <=100, areaHa optional number), season.create(name,kind crops|livestock,enterpriseId optional validated owner register,plotId optional,startsOn,endsOn), schedule.create(seasonId,title,date), event.create(seasonId,type health|breeding|feeding|production|observation|planting, date,quantity optional,unit optional,note). Schedules can be embedded season.schedule array. NO harvest here, business owns harvest atomics. FarmProduction.vue props state (full API snapshot), busy Boolean, emits command(payload); keep forms drafts until success through wrapper result if needed. Map component may use installed Leaflet client only, public defaultOSM tile attribution, no third-party new APIs. Root command accepts payload emitted.

Actions team.invite(email,role manager|worker|viewer) generates 32byte share token hashed stored, returned once via result, expiry7days. No email sending, no autoaccept. team.accept(token) matches signed-in email exactly, no legacy email identity linking; returns farmId. team.remove(userId) owner only immediatelyrevokes. tasks.create(title,dueOn,assigneeId optional membership/account or owner,seasonId optional), tasks.complete(id,completed Boolean), tasks.consume(id,inventoryId,quantity) assigned worker only, decrement stock atomically and append movement with actor/task/season refs. Rejection must have no mutation persisted. team.invite cannot grant owner. views exclude token hashes, emails except owner if needed, no account passwords. FarmOperations.vue props state,busy,section(team|operations), emits command(payload). Include invitation accept UI even own emptyfarm; actual invited accounts can choose shared farm root. Preserve legacy roster via FarmTeam separately, do not overwrite that file. Teamaccess role actual authorization only within new workspace tools. Members cannot access owner profile/settings.

FarmBusiness.vue props state,busy emits command(payload), include manual sales orders, printable invoice, delivery and grouped profit. Do not edit existing marketplace.
