# Application screenshots

Captured October 24, 2026 from the actual FarmBuddy application running locally with an isolated demo workspace. These are UI screenshots, not hand-drawn concepts or live customer records.

- `app-overview.png`: dashboard overview and farm job entry points.
- `app-production.png`: crop seasons and production actions.
- `app-tasks.png`: daily operations board with sample tasks created using the authenticated management API.
- `app-plant.png`: plant photo selection interface. No scan result or diagnostic accuracy is implied.
- `app-chat.png`: assistant entry interface. Local preview has no Workers AI binding, so it honestly displays the unavailable state. This screenshot is not evidence of a live AI answer.

All captures are 1600 × 1000 pixels. Preserve the 8:5 ratio. The development toolbar was hidden for capture. No customer accounts, emails, credentials, provider keys or private farm locations are included. The Green Acre Farm name and sample tasks belong to the local demo fixture. No production data was changed for this presentation.

The landing-page design reference is the app's own `AppPreviews.vue` and `FarmToolkit.vue`: rounded feature showcases, forest-green surfaces, warm accent panels and prominent framed application views.
